# Contributing

Start with an issue describing the player problem and pack version. Keep changes
small and preserve existing quest and task IDs so updates retain player progress.
Keep Create, Aeronautics, Oritech, Psi, Occultism, and space optional.

Run `python3 tools/build_pack.py` to check the manifests and generate the client
and server archives. Test relevant gameplay in a separate world. Only contribute
material you have permission to use, and identify third-party sources and terms.
Review LICENSE before redistributing this project's original content.
