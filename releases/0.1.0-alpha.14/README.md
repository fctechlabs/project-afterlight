# Project Afterlight 0.1.0-alpha.14

Minecraft 1.21.1 · NeoForge 21.1.251 · Java 21

- **Afterlight-0.1.0-alpha.14-CurseForge.zip**: clean client reference build. Download the ZIP and import it into the CurseForge app to play. For website submission, use **Export Profile** on the installed profile and upload that app-generated ZIP, as required by CurseForge's submission policy.
- **Afterlight-0.1.0-alpha.14-server.zip**: matching server bootstrap pack. Follow the included `docs/SERVER.md`. On CurseForge, upload it as an Additional File attached to the client pack.
- **checksums.json**: SHA-256 hashes and file sizes for both archives.

These archives contain the pack's runtime settings, quests and scripts, with publisher references for mod downloads. Mod jars, local worlds and private development files are excluded.

The client contains 379 mod jars after launcher installation, 3,612 quests across 72 chapters, two island choices, and a separate 25% Chance Cube quest bonus. The server installation resolves 336 mod jars. This is an early alpha; back up worlds before updating.

Upload one client ZIP to CurseForge, rather than dragging this whole directory or GitHub's source ZIP into its uploader. Select Alpha, Minecraft 1.21.1 and NeoForge where offered.
